Load script lines

Paste the lines or load a .txt or .csv file. One line per row. New lines are added after any you already have, and Sound FX stay as they are.

Optional formatting 
# Section name        → starts a new group (e.g. # Level 1, # Combat)
Get off my dirt!      → a line
(angry, shouting)     → a direction in ( ) or [ ] gets pulled out as a note
WM_014 | Hello there  → your own label before a | or tab
> Off my dirt!        → a line starting with > is an alternate of the line above
WORM MAN: Hi          → a "Worm Man:" speaker prefix is removed

Export

Makes a .zip of WAV files with the global processing applied, plus a manifest spreadsheet (CSV) listing every file, its label and its text.

Shortcuts

Space   start / stop a take
Esc     cancel the take you're recording (throws it away)
Enter   next item
↑ ↓   previous / next item
P       play the latest take
S       star the latest take as a keeper
B       toggle processing bypass

Everything is saved in this browser automatically. Use the same browser and the same file location each time. Export a zip now and then as a backup.
